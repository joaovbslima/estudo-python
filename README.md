## 📌 **Curso Python para Dados: primeiros passos**

O curso aborda os conceitos fundamentais de lógica de programação com Python, focando na aplicação prática para análise e manipulação de dados.

### 📚 Principais Tópicos Aprendidos
- **Variáveis e Tipos de Dados:** Manipulação de strings, inteiros, floats e booleanos.
- **Estruturas Condicionais:** Uso de `if`, `elif` e `else` para tomada de decisões.
- **Estruturas de Repetição:** Laços `for` e `while`.
- **Estruturas de Dados:** Trabalhando com listas e dicionários.
- **Funções:** Utilização de funções built-in
